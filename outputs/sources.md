# Project Data Sources

The AI workflow for this project utilizes a dataset of 31 public customer reviews.

## Data Collection Sources
The reviews were aggregated from the following platforms:
- **Google Play Store**: App reviews for the Groww application.
- **Apple App Store**: User feedback and ratings.
- **Reddit**: Discussions and complaints within investing and finance communities.
- **Twitter (X)**: Real-time user mentions and support queries.

## Dataset Details
- **Total Reviews:** 31
- **Format:** CSV
- **Fields:** `review_id`, `review_date`, `rating`, `review_text`, `source`, `product`
- **Date Range:** July 2026 - September 2026
